- android/local.properties written with sdk.dir pointing at
  C:/Users/Nick/AppData/Local/Android/Sdk (forward slashes — a Java properties
  file treats a lone backslash as an escape, so C\:\Users\... silently
  resolves to C:UsersNick...). Already gitignored by Capacitor's own
  android/.gitignore.
- npm scripts:
    android:sync  = npm run build && cap sync android
    android:apk   = npm run android:sync && android\gradlew.bat -p android assembleDebug

  NOTE the apk script does NOT use "cd android && gradlew.bat". That form
  works from PowerShell but fails from Git Bash, which sets
  NoDefaultCurrentDirectoryInExePath=1 and so stops cmd.exe resolving
  gradlew.bat in the current directory. The explicit path plus -p works from
  any shell. Windows-only either way (gradlew.bat).

- APK OUTPUT PATH:
